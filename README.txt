ВАЖЛИВО ДЛЯ RAILWAY:
1. Додайте PostgreSQL до Railway-проєкту.
2. Переконайтеся, що сервіс сайту має DATABASE_URL.
3. Variables:
   SESSION_SECRET = довгий випадковий секрет
   ADMIN_PASSWORD = ваш новий пароль Yung_Marvelov
4. Якщо Yung_Marvelov вже існує зі старим паролем, тимчасово додайте:
   RESET_OWNER_PASSWORD = true
   Після успішного входу видаліть цю змінну або змініть на false.
5. Start command: npm start
